## 社長への確認事項（詳細化の優先順）

### 1. 工場の足場工事：ashiba2
- 当社が担当した作業は足場の設置・解体のどこまでか。写真に写る建屋の改修・補修について、自社で担当した作業が別途あるか。

- 実際の課題と、当社が行った調整・工夫・安全配慮。稼働中施設だったかどうかも記録で確認。
- 施主/元請/施設からの公開条件、人物・看板等の公開可否、追加写真の有無。

### 2. 高速道路の足場・遮音パネル・検査路撤去：ashiba / shaon / kosoku
- 3写真の現場は同一か別か。各写真で当社が担当した設置・撤去・復旧の具体的な工程と範囲。

- 時期、公開可能な地域、数量・工期、施工条件と実際の工夫、契約上の立場。
- 写真の権利・施設/元請等の公開条件と、追加掲載できる資料・写真。

### 3. 耐震補強・その他の既存写真
- 当社の担当作業と、写真に写る他社施工範囲の切り分け。補強工法・性能・効果は裏付け確認後のみ記載。

- 人物、車両番号、看板、建物名、所有者・元請等の公開条件。

### 4. 新しい営業条件の追加に必要な確認
