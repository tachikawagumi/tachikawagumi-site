## 検証結果

実行コマンド（リポジトリのルートから）：

```sh
python tools/verify-seo.py
node tools/verify-contact-regression.cjs
git diff --check
```

- **技術SEO：合格**。公開対象8ページでtitle／descriptionの重複なし、H1各1件、canonicalと既存URLの整合を確認。JSON-LD全件をJSONとして解析。サイトマップ8件・robots.txtを保持。ローカルリンク、フラグメント、画像・CSS・JSの参照先の存在確認でエラーなし。
- **画像：維持**。既存実写真・WebP・AVIF・srcset・sizes・width／height・altを変更していない。画像要素のalt・寸法属性を確認（空srcの動的ライトボックスは除外）。写真の再承認や新規掲載判断は行っていない。
- **実績3件：確認**。課題・方法・担当範囲・完成写真の説明が詳細ページにあり、一覧→詳細→相談フォームへのリンクが存在。写真紹介と詳細事例を区別している。メッシュフェンスは新設にせず、隣接建物の足場は他社施工の説明を保持。
- **レスポンシブ：合格**。Chromeの同一オリジンiframeで3ページ×360／390／768／1440pxの12条件を確認。フレーム内有効幅は縦スクロールバー分15pxを除く345／375／753／1425pxで、各条件でscrollWidth＝clientWidth。スマホ工場ヒーロー・追加本文、PC実績カードを目視確認。実機端末での検証ではない。
- **問い合わせ遷移：合格**。プレビューの工場改修CTAをクリックし、フォームの「工場改修・補修」選択をDOMで確認。factory／sound-barrier／fence／不正クエリの自動選択・フォールバックをモックでも確認。
- **計測：合格**。既存コードを実行したモックでphone_click／contact_clickの発火と工事種別を確認。成功応答時だけgenerate_leadが1回発火し、HTTP失敗・通信失敗・入力検証失敗では0回。送信中の重複操作でもリクエストは1回。失敗時はresetしない。実際のFormspree送信は未実施。
- **既存設定：変更なし**。3ページの非JSON-LDスクリプト、トップのform全体、共通contact-ui.js／CSS、サービスCSS、robots.txt、sitemap.xmlを基点と比較。GA4 `G-0YE8VVH5FC`、Formspree `xaeqnqde`、通知先、公開設定を変更していない。通知先設定画面の再確認は未実施。
- **容量**。工場ページのHTMLは11,278→15,147 bytes、ローカルgzip参考値4,449→5,395 bytes。トップ55,915→56,229 bytes、実績一覧18,101→18,294 bytes。画像・外部依存・実行スクリプトは追加していない。この容量確認を表示速度の改善実績とは扱わない。
